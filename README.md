# DaleSeo.github.io

이 저장소는 [daleseo.com](https://www.daleseo.com)이 Gatsby와 GitHub Pages로 운영되던 시절의 **빌드 산출물 보관소**입니다.

## 오탈자나 오류를 발견하셨다면

[이슈로 제보](https://github.com/DaleSeo/DaleSeo.github.io/issues/new/choose)해 주세요. 확인 후 블로그에 반영하고 이슈에 답을 남기겠습니다.

**Pull Request는 반영할 수 없습니다.** 이 저장소에는 글의 원본이 없어서, 여기서 파일을 고쳐도 블로그에는 아무 영향이 없습니다. 번거로우시겠지만 이슈로 남겨 주시면 제가 반영하겠습니다.
